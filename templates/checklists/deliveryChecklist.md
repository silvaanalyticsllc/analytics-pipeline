# Client Delivery Checklist

## Phase 1 – Intake
- [ ] Dataset received
- [ ] Format confirmed (CSV/Excel)
- [ ] Columns reviewed
- [ ] Missing values checked
- [ ] Date ranges validated

## Phase 2 – Processing
- [ ] Raw file stored (unchanged)
- [ ] Script executed
- [ ] Data cleaned
- [ ] Transformations applied
- [ ] Clean dataset exported

## Phase 3 – Validation
- [ ] Row counts verified
- [ ] Aggregates checked
- [ ] Sample rows reviewed

## Phase 4 – Hosting
- [ ] Uploaded to Google Sheets
- [ ] Sheet structured
- [ ] Permissions set

## Phase 5 – Dashboard
- [ ] KPIs created
- [ ] Charts built
- [ ] Filters added
- [ ] Layout cleaned

## Phase 6 – Review
- [ ] Data matches visuals
- [ ] No broken charts

## Phase 7 – Delivery
- [ ] Draft sent
- [ ] Feedback collected

## Phase 8 – Revision
- [ ] Changes applied
- [ ] Version updated

## Phase 9 – Final
- [ ] Final dashboard delivered
- [ ] Permissions updated
